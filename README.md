## 📂 Repository Structure

جميع التحديات موجودة داخل المجلد الرئيسي:

`challenges/`

ستجدون داخل هذا المجلد مجلدات التحديات وملفاتها المرتبطة.

## 📦 What is included?

الأرشيف يتضمن ملفات وموارد التحديات، ومنها:

- **Challenge Binaries:** الملفات التنفيذية التي تعاملتم معها أثناء حل التحديات.
- **Source Code:** الأكواد المصدرية للبرامج، عند توفرها.
- **Exploit Scripts:** سكربتات الاستغلال المستخدمة لحل التحديات.
- **Writeups / Solutions:** الشروحات والخطوات التي توضح طريقة الوصول إلى الحل.
- **Flags:** الأعلام الصحيحة الخاصة بالتحديات.
- **Supporting Files:** المكتبات والملفات الإضافية اللازمة لبعض التحديات.

قد تختلف الملفات الموجودة من تحدٍ إلى آخر بحسب متطلباته وطريقة بنائه.

## ⚠️ Important – Read Before Exploring

**تنبيه: هذا المستودع يحتوي على الحلول الكاملة للتحديات!**

بما أن الهدف من الأرشيف هو المراجعة والتعلم، نوصي بالتالي:

1. إذا كنت تريد إعادة تجربة التحديات، حاول حلها بنفسك أولاً قبل الاطلاع على ملفات الحلول.
2. لا تشغّل سكربتات الاستغلال مباشرة دون محاولة فهم طريقة عملها.
3. اقرأ الكود المصدري وحاول تحديد الثغرة بنفسك.
4. استخدم ملفات الاستغلال كمرجع لفهم كيفية بناء الـ Payload واستغلال الثغرات.
5. قارن بين طريقتك في الحل والحل الموجود في الأرشيف، وحاول فهم سبب نجاح كل خطوة.

## 🛠️ Running the Challenges

بعض التحديات قد تحتاج إلى بيئة Linux ومكتبات أو أدوات معينة حتى تعمل بالشكل الصحيح.

قد تحتاج إلى أدوات مثل:

- GCC / G++
- GDB
- GEF / Pwndbg
- Python 3
- Pwntools
- Checksec

تأكد من مراجعة ملفات كل تحدٍ لمعرفة متطلباته قبل محاولة تشغيله.
